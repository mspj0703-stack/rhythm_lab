# BEATDASH::Revive version policy

- User-facing app name: `BEATDASH`.
- Internal project / codename: `BEATDASH::Revive`.
- Reviewed baseline: v3.0.0 Gameplay Feel / MV Media work.
- Current development target: v4.0.0 — Library & Records + UI/SFX overhaul.
- Features are completed and validated as a version before starting the next feature version.
- Emergency fixes may be patched without expanding feature scope.

## v3 baseline retained in v4

- Perfect ±35ms / Great ±75ms / Good ±120ms.
- Hold release / regrab behavior from the reviewed v3 implementation.
- Perspective highway, lower judgement line and Flick distinction.
- Companion MP4 -> WebView `<video>` playback and matched WAV analysis source.

## v4 scope

- Local Library and song detail flow.
- Per-chart play records and best records.
- Full Combo / Perfect Combo status and result feedback.
- Per-song Timing Offset.
- UI overhaul.
- Full SFX foundation and volume settings.
- Future-compatible song/chart IDs for Editor, Community Charts, Cloud, Co-op and PvP.
