# BEATDASH v5.0 Phase 2 — Android 실기기 검증 체크리스트

> 상태: **미수행**. 이 체크리스트의 모든 항목은 아직 실기기에서 확인되지 않았다.
> 자동 테스트(Vitest/Playwright/소스 계약 테스트)는 실기기 검증을 대체하지 않는다.
> Android 앱(Kotlin)은 이번 환경에서 Gradle/SDK 네트워크가 막혀 **컴파일되지 않았다.** 실기기 전에 `./gradlew assembleDebug`부터 통과시킬 것.

기기 정보(모델 / Android 버전 / WebView 버전 / 네트워크)를 아래 표 맨 위에 적고, 항목마다 PASS / FAIL / N/A와 메모를 남긴다.

## 0. 빌드·설치
- [ ] `./gradlew assembleDebug` 성공
- [ ] 설치 후 앱 실행, 버전 5.0.0-rc.phase2 표기 확인
- [ ] 기존 Library / Records / Settings 유지 (v3/v4 데이터가 있는 기기에서 업데이트 설치)

## 1. 멀티터치 (P0)
- [ ] Hold 유지 중 다른 손가락으로 Tap → Hold 끊기지 않음
- [ ] Hold 유지 중 다른 손가락으로 Flick → Hold 끊기지 않음
- [ ] Hold 두 개 동시 유지 + Tap / Flick
- [ ] 다른 손가락을 떼거나 시스템 제스처로 취소돼도 Hold 유지
- [ ] 4손가락 동시 입력, 빠른 연타·연속 Flick
- [ ] 한 번 터치가 두 번 판정되지 않음
- [ ] 레인 위 길게 누르기에서 복사/컨텍스트 메뉴/텍스트 선택이 뜨지 않음

## 2. MASTER 표기
- [ ] Companion 난이도 스피너에 EASY/NORMAL/HARD/EXPERT/MASTER
- [ ] MASTER로 생성한 곡이 웹/Library/Result에서 MASTER로 표시 ("EXTREME" 노출 없음)
- [ ] 기존 extreme 채보·기록이 MASTER로 정상 표시

## 3. 미디어 준비 / 느린 네트워크 (P0)
- [ ] 플레이 시작 전 준비 진행 표시 후 시작 (준비 전 노트 진행 없음)
- [ ] 느린 Wi-Fi/데이터에서 준비 지연 → 준비 완료 후에만 시작
- [ ] 플레이 중 버퍼링 발생 시 판정 정지 → 재개 후 정상 진행
- [ ] MV 로드 실패 시 "다시 시도 / MV 없이 플레이" 선택, 오디오 단독 진행 가능
- [ ] 재시작/재개 시 미디어 재다운로드 없음
- [ ] 오디오와 노트 싱크(체감) 이상 없음, 화면 off/on 후 복귀

## 4. Pause 메뉴 / 카운트다운 (P1)
- [ ] 일시정지 메뉴: 계속하기 / 다시 시작 / MV 설정 / 곡 리스트로 돌아가기
- [ ] 계속하기·다시 시작 → 3-2-1 카운트다운 중 오디오/MV/노트/입력 정지, 이후 같은 위치에서 재개
- [ ] Pause 중 Hold를 누르고 있던 경우: 누르고 있으면 계속, 뗐으면 400ms 안에 다시 잡기 가능
- [ ] MV 설정이 Pause에서 즉시 적용되고 오디오 위치가 움직이지 않음
- [ ] 곡 리스트로 돌아가기 → 확인창 → Record 저장 안 됨, 오디오/MV 정지
- [ ] 왼쪽 "메뉴로 가기" 버튼이 플레이 화면에 없음
- [ ] 안드로이드 시스템 Back → Pause (플레이 종료되지 않음), Pause에서 Back → 계속하기가 아닌 안전한 동작 확인

## 5. 전체화면 / 방향 잠금 (2C)
- [ ] 플레이 진입 시 시스템 바 숨김 + 방향 고정, 노치/펀치홀/제스처바 영역 침범 없음
- [ ] Pause / 카운트다운 / 다시 시작 동안 방향 잠금 유지
- [ ] 곡 리스트 이동, 결과 화면 종료, 앱 백그라운드→복귀, 비정상 종료 후 방향 잠금 해제
- [ ] 세로/가로 폰, 태블릿에서 플레이필드가 화면에 맞게 배치

## 6. Maker v1
- [ ] 모바일 터치로 노트 추가/삭제/이동/레인 변경/시간 변경/Tap↔Hold/Hold 길이/Flick
- [ ] Snap 1/4, 1/8, 1/16, 1/32, OFF / Undo·Redo / 저장
- [ ] TEST PLAY 후 기록이 저장되지 않음
- [ ] Validator ERROR가 있으면 공유가 막힘

## 7. Community
- [ ] 사람이 편집한 채보만 업로드 가능 (AI 원본·수정 없는 복사본 불가)
- [ ] 목록/검색/정렬/난이도·플랫폼 필터
- [ ] 다운로드 시 같은 곡이 Library에 있을 때만 자동 연결, 기록은 chartId별로 분리
- [ ] 본인 채보만 수정/삭제 가능
