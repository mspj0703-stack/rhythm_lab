# BEATDASH v4.8.0-rc.1 · Android 실기기 재생 P0 검증 체크리스트

전제: 이 패치가 들어간 Web(Railway)을 배포한 뒤 앱을 실행한다. **앱 데이터 삭제/Library 초기화 금지** — 기존 저장곡 그대로 확인한다.
영상 오류가 나면 오류 박스에 `진단 · …`(code / networkState / readyState / 종류 / 경로)가 표시된다. **캡처해서 전달**해 주세요(원인 확정용).

| # | 시나리오 | 방법 | 기대 결과 |
|---|---|---|---|
| 1 | 기존 Library 곡 실행 | v4.0/v4.75 저장곡 선택 → 플레이 | 재생됨. 영상 실패 시에도 "영상 로드에 실패해 오디오 모드로 재생합니다." 후 카운트다운→플레이. "자동 복구 한도" 화면이 나오면 실패 |
| 2 | 새 곡 실행 | 새로 분석/저장 후 플레이 | 정상 재생, MV 동기 |
| 3 | MV 정상 곡 | MV 있는 곡 | 영상+소리, 노트 싱크 정상, 알림 배너 없음 |
| 4 | MV 실패 → audio-only | MV 손상/없는 곡 | 배너 표시, 소리만으로 카운트다운·판정·결과 화면까지 진행 |
| 5 | Pause → Resume | 플레이 중 일시정지 후 재개 | 이어서 재생, 위치 유지 |
| 6 | Restart | 일시정지 메뉴/결과 후 RETRY | 처음부터 정상 재시작, 소리 중복 없음 |
| 7 | background → foreground | 플레이 중 홈 → 복귀 | 자동 일시정지, 재개 시 정상 |
| 8 | 같은 곡 재실행 | 종료 후 같은 곡 다시 | 정상, 이전 소리 잔류 없음 |
| 9 | 다른 곡으로 변경 | Library에서 다른 곡 | 이전 곡 소리 즉시 정지, 새 곡 정상 |
| 10 | 앱 완전 종료 → 재실행 → Library 곡 | 최근 앱에서 스와이프 종료 후 재실행 | 곡 목록 유지, 재생 정상 |
| 11 | "재생 다시 시도" | 오류 박스가 나왔을 때 | 루프 없이 재시도; 같은 영상이 또 실패하면 audio-only로 전환 |

통과 기준: 1·4·10에서 오디오가 정상인데 재생이 막히지 않을 것.
실패 시 전달: 시나리오 번호, `진단 ·` 줄 캡처, 앱 버전(v4.8.0-rc.1).
